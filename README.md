# 昱弘网通 NetKit

给现场工程师用的**网络万能表**。一台机器装上它，网络上能看的、能测的、能改的，都在里面，
而且都是可视化的——不用记命令、不用开终端。

**别人家的路由器有什么，它有什么；别人家的路由器没有的排障能力，它也有。**

## IPv6

**双栈从第一行代码就写进去，不设「IPv6 期」。** 见 `docs/设计.md` 的「IPv6 支持」一节。

三条落在代码上的纪律：

1. 地址类型一律用 `netip.Addr`，**不用 `net.IP`**（后者不可比较、不能当 map key、不带 zone，
   而且同一个 v4 地址有 4 字节和 16 字节两种互不相等的表示）
2. 链路本地地址**存「地址 + 接口名 + 接口索引」，不存拼好的字符串** ——
   zone 的写法每个平台都不一样（`%en0` vs `%12`），拼死了就等着在另一个平台上炸
3. **「一台设备一个 IP」的数据结构一律是错的**。v6 一块网卡天生就有好几个地址
