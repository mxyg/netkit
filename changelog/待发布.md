# 技术说明
壳层改版：六个一级入口 + 新手/专家双模式 + 深浅色三态 + 设置页（docs/UI改版设计.md 第三、四节，落地顺序第 1–3 步）
- 顶栏新增「新手 / 专家」模式段与主题快切钮：新手（默认）只露常用页，专家全量展开；切回新手时若停在专家页自动退回总览，不留悬空态
- 导航改为六个一级入口的任务树（开始 / 网络 / 设备 / 修复 / 工具 / 设置），可折叠组头、状态记在本地；新手模式每个条目带一句人话说明（第二行），PRO 分隔小标提示往下是专家条目
- 新增面包屑（入口 / 页名，同名单页不重复）与底部状态栏（工具数 / 模式 / 所在页 / 后端地址，全部从能力表现算，不写死数字）
- 深浅色三态主题：跟随系统 / 深 / 浅，落在 <html data-theme>；theme.css 新增显式浅色块，与媒体查询里那份是同一组值（两处只许一起改）；顶栏按钮三态循环，设置页有完整三选
- 新增设置页四卡：外观与语言（主题三选 + 五语按钮）、连接与端口（后端地址 / 规范版本 / 一致性自检 / 工具数，现读 /ots）、批准记录（改系统的动作清单从能力表 class=mutate 现算）、关于
- 两个任务视图页是原页合体，不另抄逻辑：网络状态 ← 连通性 render；局域网里有什么 ← 网段扫描 + 拓扑 render；能力索引（page-index）经 alias 兜底，右栏与相关页照常
- 新增「第一次用」引导页（三步上手 + 四件事直达）；会话中心 / 批量任务 / Windows SSH 桥 / 诊断包历史 / 剧本库先上诚实骨架：只说等哪个后端工具、现在能去哪儿做，不放假按钮
- ⌘K 搜索按当前模式过滤；总览「按问题找」也随模式与 alias 过滤
- i18n：190 条新键补齐 en/ja/ko/ru（part-15-1），历史分片里 40 条源码已不存在的陈旧键清除；四语 3262/3262 全覆盖，merge/audit 通过（audit 余 22 条均为存量的动态键与卡片代号类提示，基线为 26）

# 用户更新说明
## 新增
- 打开后默认是「新手」模式：左边只有六个入口（开始 / 网络 / 设备 / 修复 / 工具 / 设置），每个条目下面有一句说明；右上角一键切「专家」，全部页面展开，功能一个不删
- 顶栏多了一个主题按钮：跟着系统 / 深 / 浅，点了马上换；设置页里也可以选，还能换五种语言（简体中文 / English / 日本語 / 한국어 / Русский）
- 新的设置页：能看到后端地址和连接状态、哪些操作属于「要批准」的一类；换语言、换主题都在这里
- 左侧栏每个组可以折叠；底部多了一条状态栏，随时能看到后端连没连上、有多少个工具

## 优化
- 「网络状态」「局域网里有什么」把原来分散的几页合成一个入口，先看到结论再深入；原来的页在专家模式里都还在
- 第一次用的引导更直接：选语言主题 → 跑一次体检 → 直接去办四件事之一

# 技术说明
新增：网线直连的 Windows 可从本机页面一键安装 SSH
- 远程设备页增加「网线那头开 SSH」：本机在各 IPv4 上开 8770 页面，对方下载 go.cmd 后安装 OpenSSH 并放行 22
- 脚本进度经 POST 回本机；状态里带 arp 邻居和 22 是否已开
- 对方下载的文件名带下载时间（nk-ssh-年月日-时分秒.cmd），重新下载名字会变，避免一直用旧文件

# 技术说明
修复：远程操作按钮一点就没反应
- 已登记设备再连时，如果这次握手用了另一种主机密钥算法，会误报「主机密钥变了」。现在按登记时的算法去要公钥
- 「连上去干活」里增加「在网通里看这台的屏幕」：对方跑网通自己的画面进程，不依赖系统远程桌面，家庭版也能看、能点
- 「连上去干活」里执行、传文件、远程桌面的按钮把翻译函数 t 盖掉了，一点就抛错，批准框和后续动作都不会出现
- 按钮文字改用另一个变量保存，点下去会先显示「进行中」，再弹出批准框
- 本机不改系统设置。对方安装仍要 Windows 管理员确认
- 远程桌面单独窗口。画面上的鼠标跟着对方当前光标形状变，不再固定成十字
- 窗口上可以勾选「显示远端鼠标」，勾上后对方鼠标的位置和形状按每一帧画在画面上
- 拖进窗口的文件放到对方正打开的文件夹，没有打开的文件夹就放到桌面
