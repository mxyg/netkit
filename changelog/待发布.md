# 技术说明
新增：网线直连的 Windows 可从本机页面一键安装 SSH
- 远程设备页增加「网线那头开 SSH」：本机在各 IPv4 上开 8770 页面，对方下载 go.cmd 后安装 OpenSSH 并放行 22
- 脚本进度经 POST 回本机；状态里带 arp 邻居和 22 是否已开
- 对方下载的文件名带下载时间（nk-ssh-年月日-时分秒.cmd），重新下载名字会变，避免一直用旧文件

# 技术说明
修复：远程操作按钮一点就没反应
- 已登记设备再连时，如果这次握手用了另一种主机密钥算法，会误报「主机密钥变了」。现在按登记时的算法去要公钥
- 「连上去干活」里增加「在网通里看这台的屏幕」：对方跑网通自己的画面进程，不依赖系统远程桌面，家庭版也能看、能点
- 「连上去干活」里执行、传文件、远程桌面的按钮把翻译函数 t 盖掉了，一点就抛错，批准框和后续动作都不会出现
- 按钮文字改用另一个变量保存，点下去会先显示「进行中」，再弹出批准框
- 本机不改系统设置。对方安装仍要 Windows 管理员确认
- 远程桌面单独窗口。画面上的鼠标跟着对方当前光标形状变，不再固定成十字
- 窗口上可以勾选「显示远端鼠标」，勾上后对方鼠标的位置和形状按每一帧画在画面上
- 拖进窗口的文件放到对方正打开的文件夹，没有打开的文件夹就放到桌面

# 用户更新说明
## 新增
- 网线连着一台还没开远程的 Windows 时，可以让对方打开一个网页、双击下载的文件，装好后就能登记、传文件
- 看对方屏幕时，鼠标会变成对方那边的形状；也可以勾选，把对方的鼠标一起显示出来
