# 技术说明
出包链路（scripts/publish-github.sh）
- 新增一键发布到 GitHub Releases：后端出包 → 目录名软链映射 → electron-builder 三平台安装包 → 汇总改名（yuhox-netkit-<版本>-<平台>）+ SHA256SUMS.txt → gh release create 上传。对外分发走 GitHub（免费分发，不占自家桶）
- 修 trace_test 的真机跳过判据：原来只 exec.LookPath 查「文件在不在」，macOS 的 traceroute 是 setuid 二进制、在受管控会话里 exec 会 EPERM —— 文件在但跑不动时整个 go test 闸门恒挂。现在真试跑一次，跑不通就诚实跳过
- 顺手 gofmt 三个落格式时漏掉的文件（batch.go / filebrowser.go / topo_ui_words_test.go）

界面版式对齐原型（docs/原型/index.html；docs/UI改版设计.md 第四、五节）
- 首页按原型重排：快捷条 + 四张图标任务卡（网通不通 / 连一台机器 / 抓个包看看 / 出问题了）+ 网络健康卡（环心放 checkup 判定词 —— 后端没有数字分就不编一个；四行指标 出网/丢包/流量占用/时钟偏差 全部 checkup·bandwidth.top 现量）+ 正在跑卡（复用顶栏探针与本会话批量任务）+ 设备一览表 + 最近动作表（remote.audit.tail 现拉）
- 设备详情改原型 split 版式：左列设备名单（标签过滤 / 探测 / ＋ / 批量命令），右侧子页签（概览 / 终端 / 文件 / 桌面 / 剧本 / 审计）+ 四格状态 + 身份与通道卡 + 审计留痕表（table-layout:fixed 防溢出）；换页签不断终端会话
- 导航补齐独立的 终端 / 文件 / 剧本 页（对选中设备干活；没选机器先挑一台）
- 原型组件 CSS 移植（映射到现有令牌）：pgroup/sdot/pill gold·blue、btn primary/ghost/sm、card 的 ch/cb 结构、softcap 表头、quickbar、taskcards、gauge 环形、meter、tasklist/pbar、devsplit（dlist/drow/detailpane/subtabs/stat4/kv）、emptybox —— 版式照原型，颜色一律 var()
- i18n：新键 56 条补齐 en/ja/ko/ru（part-21-1 / part-22-1），被替换的旧版式陈旧键 76 条清除；四语 3438/3438 全覆盖，merge 0 问题（audit 20 条均为存量提示，与基线持平）
- 顶栏新增「任务中心」入口与弹出面板：谁在跑（后端探针判定，5 秒一轮）、跑到哪（跳对应页）、怎么停（只配在后端真有 stop 工具的七类上 —— 抓包 / 对端抓包 / DHCP / 质量 / 对测口 / 文件共享 / 手机门户；停走 call() 的批准框）；本会话起过的批量任务列进度（remote.task.status 现查），后端没有取消工具就不放取消钮
- 面板版式三段：头部（标题 + 收起）→ 大数字重心（此刻在跑几件，空闲就画 0，右侧「再刷一次」手动插队探针）→ 图标行（每类任务一枚笔划图标，颜色跟主题走；批量任务画真进度条 —— finished/total 是后端报的，宽度假不了）；底注自写「结果最多滞后 5 秒 —— 以各页自己那块为准」
- 原「此刻在跑」一排探针结果复用为任务中心的数据源，两处不各问一遍
- 总览页按设计瘦身，不再铺导航复制品，只留四块：这台机器的体检结论（一键重测）、接着上次干（还在跑的 + 最近用过的页 + 最近问过的，全现量）、所有设备一览（本机 + remote.device.list 现拉，点行进设备详情）、快速入口（按本机点开次数排的前六页，次数不够按导航顺序补，不编「热门」）

- i18n：新键 29 条补齐 en/ja/ko/ru（part-19-1 / part-20-1），旧总览与旧面板陈旧键 26 条清除；四语 3401/3401 全覆盖，merge 0 问题（audit 20 条均为存量动态键与卡片代号类提示，较基线 22 反少 2）

# 技术说明
修复：远程操作按钮一点就没反应
- 已登记设备再连时，如果这次握手用了另一种主机密钥算法，会误报「主机密钥变了」。现在按登记时的算法去要公钥
- 「连上去干活」里增加「在网通里看这台的屏幕」：对方跑网通自己的画面进程，不依赖系统远程桌面，家庭版也能看、能点
- 「连上去干活」里执行、传文件、远程桌面的按钮把翻译函数 t 盖掉了，一点就抛错，批准框和后续动作都不会出现
- 按钮文字改用另一个变量保存，点下去会先显示「进行中」，再弹出批准框
- 本机不改系统设置。对方安装仍要 Windows 管理员确认
- 远程桌面单独窗口。画面上的鼠标跟着对方当前光标形状变，不再固定成十字
- 窗口上可以勾选「显示远端鼠标」，勾上后对方鼠标的位置和形状按每一帧画在画面上
- 拖进窗口的文件放到对方正打开的文件夹，没有打开的文件夹就放到桌面
