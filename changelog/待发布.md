# 用户更新说明
## 新增
- 顶栏多了「任务中心」：抓包、DHCP、文件共享这类一直在跑的事，谁在跑、跑到哪、怎么停，一个入口全看得到；停的时候照旧先弹确认
- 总览页变清爽了：第一屏只留四块 —— 这台机器的体检结论、接着上次干（还在跑的事和最近用过的页）、所有设备一览、最常去的几页快速入口

## 新增（上次提交，待一并发布）
- 打开后默认是「新手」模式：左边只有六个入口（开始 / 网络 / 设备 / 修复 / 工具 / 设置），每个条目下面有一句说明；右上角一键切「专家」，全部页面展开，功能一个不删
- 顶栏多了一个主题按钮：跟着系统 / 深 / 浅，点了马上换；设置页里也可以选，还能换五种语言（简体中文 / English / 日本語 / 한국어 / Русский）
- 新的设置页：能看到后端地址和连接状态、哪些操作属于「要批准」的一类；换语言、换主题都在这里
- 左侧栏每个组可以折叠；底部多了一条状态栏，随时能看到后端连没连上、有多少个工具

## 优化
- 总览页不再把所有页面再铺一遍：想找什么用左边导航或顶栏搜索，常用的页会按你的使用习惯自己浮上来
- 「网络状态」「局域网里有什么」把原来分散的几页合成一个入口，先看到结论再深入；原来的页在专家模式里都还在
- 第一次用的引导更直接：选语言主题 → 跑一次体检 → 直接去办四件事之一

# 技术说明
修复：远程操作按钮一点就没反应
- 已登记设备再连时，如果这次握手用了另一种主机密钥算法，会误报「主机密钥变了」。现在按登记时的算法去要公钥
- 「连上去干活」里增加「在网通里看这台的屏幕」：对方跑网通自己的画面进程，不依赖系统远程桌面，家庭版也能看、能点
- 「连上去干活」里执行、传文件、远程桌面的按钮把翻译函数 t 盖掉了，一点就抛错，批准框和后续动作都不会出现
- 按钮文字改用另一个变量保存，点下去会先显示「进行中」，再弹出批准框
- 本机不改系统设置。对方安装仍要 Windows 管理员确认
- 远程桌面单独窗口。画面上的鼠标跟着对方当前光标形状变，不再固定成十字
- 窗口上可以勾选「显示远端鼠标」，勾上后对方鼠标的位置和形状按每一帧画在画面上
- 拖进窗口的文件放到对方正打开的文件夹，没有打开的文件夹就放到桌面
