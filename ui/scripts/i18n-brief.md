# 词典分片的译法契约（每个翻译 agent 先读这一份）

任务本身只有一句话：把 `.i18n-work/chunk-<箱号>.json` 里的每一条中文，译成指定语言，
写成 `.i18n-work/<语言>/part-<箱号>-<片号>.json`。下面是这件事的全部约束。

★ 为什么这些约束写成机器判据而不是靠人自觉：词典是几十片并行译出来的，
「{0} 被吃掉」这种错在界面上会打出裸的 `{0}`，而没人会去改别人那一片。
所有判据在 `scripts/i18n-lib.cjs`，跑 `node scripts/i18n-check-part.cjs <语言> <箱号>` 就是它。

## 一、输入与输出

- 输入：`.i18n-work/chunk-NN.json` —— 一个 JSON 数组，约 291 条中文原文。
- 输出：`.i18n-work/<lang>/part-NN-K.json`，每片是一个扁平对象 `{ "中文原文": "译文" }`。
  **一箱拆成 3 片左右、每片 90–100 条**：一次 Write 写 60 KB 的巨型 JSON 真的会失败
  （已经有 agent 死在这上面）。每片各自必须是合法 JSON。
- 这一箱的 key 必须**全部**出现在某一片里，一条不漏、一条不多。
  自检器把整箱的并集对着输入数，漏几条报几条。
- 中文原文就是运行时的 key，所以**不许改 key**（改一个字等于换了一个 key，
  那条译文永远用不上，界面上那一句就退回中文）。

## 二、机器判据（一条都不许绕过）

1. **槽位**：`{0}` `{1}` … 的集合必须与原文完全一致。少一个 → 界面打出裸 `{0}`；
   编号改了 → 两个值串位。也不许为了语句通顺把 `{0}` 和 `{1}` 对调。
2. **HTML 骨架**：标签名、个数、嵌套照原样。
   `id` `class` `style` `name` `type` `data-*` 这些**结构性属性的值一个字符都不许变**
   （改了就是把脚本锚点、样式、表单字段弄坏，而界面上看不出来）；
   `placeholder` `title` `aria-label` `alt` `content` 的值**是文案，必须译**。
   JSON 里的引号要转义（`\"`），转义写错骨架就对不上。
3. **还留着原文**（这一条按语言判，四种不一样）：
   - `en` / `ru`：译文里出现任何一个中日韩字符就红。
   - `ko`：连着两个汉字就红（现代韩文界面按约定全写谚文）。
   - `ja`：连着四个汉字才红 —— 日文界面本来就用「 秒」「出口 MTU」「日本語」这类与中文同形的正字，
     所以三字以内的同形是允许的（这是**已知放过**的一类，不是判据漏了）。
   - 原文本来就没汉字的（`VLAN ID`、`Bytes/s`）照抄就是正解。
4. **不许译的东西**：工具名与判定码（`net.dhcp.leases`、`bandwidth-busy`）、
   命令行与路径（`pktmon`、`/dev/bpf*`、`launchctl bootstrap`）、
   协议缩写（DHCP、VLAN、RTMP、GB28181、PoE、MTU…）、举例地址
   （`192.168.1.20`、`203.0.113.9`、`example.com`）、`★` `△` `✓` 这类符号、
   排版用的空白与换行。**品牌 `昱弘网通` 不译。**
5. 需要整段照抄的中文（客户站点名、程序打印的中文路径）只能走
   `scripts/i18n-glossary.md` 的「一·b」那一节 —— 那是唯一一扇门，走门不要拆墙。

## 三、文风

现场网络工程师用的工具。短句、祈使、不修饰。
`「」` → 该语言引号；`、` → `,`（日韩用各自顿点）；`——` → `—`。
标签与按钮不加句点；表头用短名词短语；`★` 在原文哪里就在哪里。

★★ 译意思不译字数。很多原文是「下一步该查什么」的成段说明，
直译成机器腔等于没译 —— 那一句是要人在机房里照着做的。
行业词按英文手册里实际怎么写的选（PoE、trunk、lease、RST、MTU、bufferbloat…）。

## 四、交付前自检（必须跑，必须读输出）

    cd /Users/liuman/netkit/ui
    node scripts/i18n-check-part.cjs <lang> <箱号>

看到 `✓ <lang> 第 NN 箱（N 片）：291 条全对` 才算完。报了就改自己的译文再跑，
**不许改判据**（`scripts/*.cjs` 与 `i18n-glossary.md` 都不许动）。
其它 agent 正在别的箱子上，动判据等于把别人的活儿一起废掉。

最终消息控制在 150 字内：自检那一行输出、译了多少条、定了哪些术语基准表里没有的词。
