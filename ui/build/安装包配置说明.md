# 安装包配置说明（ui/package.json 的 build 字段）

★ `build` 字段是 electron-builder 的配置，**不允许写注释键**（25.x 的 schema 校验
会把 `//` 当未知属性直接拒绝，出包起不来）。原先写在里面的几条注释挪到这里，
内容一字不减 —— 改配置时对着这份看。

- `extraMetadata.name = YuhoxNetKit`：
  ★ Windows 安装目录用这个名字。不设的话会是 yuhox-netkit-ui（包名），
  客户看到一个古怪的目录。

- `directories.buildResources = assets`：
  ★ 图标与向导图一律来自 08-品牌资产 的下发（部署子项目标识.py），不许在这里手改。

- `extraResources`（Go 后端跟着装）：
  ★ 按平台放对应那一份（`../dist/release/${os}-${arch}`，发布脚本会把
  darwin/windows/amd64 的目录名软链成 mac/win/x64），装错架构的包表现成
  「装上了打不开」。

- `win.target = nsis (x64)`：
  ★★ 主线包只给 Win10+。Win7 要单独一份（它要 Electron 22，界面分包），
  目前 build 配置里还没有 win7 那一档 —— 真要出 Win7 包时先补配置再出。

- `nsis.include = build/installer.nsh`：
  ★ include 的是统一件所在的那份脚本：安装日志、E3xx 错误码、分步提示、
  Win7 分包检查都在里面。

- `linux`（AppImage + deb，x64/arm64）：
  Linux 按老板 2026-09-14 定的：不进桶不登记，客户要时单独发
  （现在对外分发走 GitHub Releases，见 scripts/publish-github.sh）。
